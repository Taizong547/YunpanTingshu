## 一、项目概述

这是一个 Android 原生应用，核心功能是：
- 登录 139 移动云盘（手机号+验证码）
- 浏览云盘文件夹、播放音频文件
- 支持分享链接免登录播放
- 书架收藏、播放历史、歌单管理
- 锁屏播放、睡眠定时、智能跳过片头片尾

## 四、核心模块详解

### 4.1 云盘对接模块（cloud139/）

**文件清单**：
- `Cloud139Api.kt` — 个人云盘 API 请求
- `Cloud139Headers.kt` — 请求头常量
- `Cloud139Urls.kt` — 路由 URL
- `Cloud139Signer.kt` — 请求签名
- `Cloud139Token.kt` — Token 解析
- `Cloud139Repository.kt` — 仓库层
- `TokenExpiredException.kt` — Token 过期异常
- `share/ShareRepository.kt` — 分享链接仓库
- `share/ShareSign.kt` — 分享签名
- `share/OutlinkCrypto.kt` — 分享加密

**关键接口**：
1. **路由接口**：先请求 `ROUTE_POLICY_URL` 获取云盘 host，缓存到内存
2. **列目录**：`getDisk` 接口，分页获取文件夹内容
3. **取直链**：`getOutLink` 接口，获取音频文件的播放直链
4. **分享链接**：独立的加密+签名体系，不需要登录

### 4.2 播放模块（player/）

**文件清单**：
- `PlaybackService.kt` — 前台服务（MediaSessionService）
- `PlaybackEngine.kt` — ExoPlayer 封装
- `PlaybackManager.kt` — 对外接口
- `PlayQueue.kt` — 播放队列
- `SleepTimer.kt` — 睡眠定时
- `SkipTiming.kt` — 智能跳过片头片尾

**核心流程**：
1. 用户点文件 → PlaybackManager.playTracks()
2. PlaybackEngine 调用 Resolver 获取直链
3. ExoPlayer prepare() 播放
4. MediaSession 更新通知栏
5. tick 循环每秒更新进度

### 4.3 数据模块（data/）

**文件清单**：
- `AccountStore.kt` — 账号管理（DataStore）
- `SettingsStore.kt` — 设置项（DataStore）
- `ProgressStore.kt` — 播放进度（DataStore）
- `AnalyticsRepository.kt` — 统计上报
- `cover/CoverStore.kt` — 封面管理
- `db/AppDatabase.kt` — Room 数据库

### 4.4 UI 模块（ui/）

**页面清单**：
- `browse/BrowseFragment.kt` — 云盘浏览页
- `player/PlayerFragment.kt` — 播放器页
- `bookshelf/BookshelfFragment.kt` — 书架页
- `history/HistoryFragment.kt` — 历史页
- `me/MeFragment.kt` — 我的页
- `login/LoginWebActivity.kt` — 登录页

## 五、接口合法性检查

### 5.1 139 移动云盘接口

| 接口 | 用途 | 合法性分析 |
|---|---|---|
| 路由接口 | 获取云盘 host | 公开 web API，正常使用 |
| 列目录 | 获取文件夹内容 | 登录后正常调用，未滥用 |
| 取直链 | 获取播放地址 | 个人账号自己的文件，合理使用 |
| 分享链接 | 免登录访问分享内容 | 尊重分享者权限，不破解 |

**结论**：本项目仅作为个人学习用途，使用自己的账号访问自己的云盘文件，未破解加密、未绕过权限、未批量抓取数据。分享链接功能仅解析用户主动粘贴的公开分享链接，不做爬虫。

### 5.2 风险提示
- 139 云盘的接口随时可能变更，本项目不保证长期可用
- Token 有时效性，过期需要重新登录
- 本项目仅供学习交流，请勿用于商业用途

## 七、关键设计决策

1. **为什么不用 Compose？**
   - 项目从 v1 开始就是 XML，改造工作量大
   - ViewBinding 足够用，学习成本低

2. **为什么用 Media3 不用 ExoPlayer 旧版？**
   - Media3 是 Google 推荐的新一代播放器
   - 自带 MediaSession，锁屏通知开箱即用

3. **为什么分享链接用独立加密？**
   - 139 分享链接的加密体系和个人云盘完全不同
   - 有自己的签名算法和加密方式

4. **为什么 Token 过期要专门异常？**
   - 统一处理过期逻辑，UI 层友好提示
   - 避免用户对着"网络错误"发呆
